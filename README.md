# 🎵 Music NFT Marketplace

🔗 **Live Demo:** https://music-nfts-ruby.vercel.app/

A decentralized **Music NFT Marketplace** where artists can mint, list, and sell music-based NFTs, and users can discover, buy, and trade exclusive digital music assets securely on the blockchain.

---

## 📌 About The Project

This project is a Web3-based marketplace that allows creators to tokenize music content into NFTs. These NFTs represent ownership of unique digital assets such as:

* 🎶 Exclusive tracks
* 🎨 Album artwork
* 🎟️ Concert tickets
* 🤝 Artist experiences

Built using blockchain technology, the platform ensures **transparency, ownership verification, and security**.

---

## ⚙️ Tech Stack

### 💻 Frontend

* Next.js
* Tailwind CSS
* React

### 🔗 Blockchain & Web3

* Ethers.js
* Solidity Smart Contracts
* ERC-1155 Token Standard

### 🛠️ Tools & Deployment

* Hardhat
* Remix
* Polygon Mumbai Testnet
* IPFS (via Pinata)

## ✨ Features

* 🔐 Connect Wallet (Web3 Authentication)
* 🎵 Mint Music NFTs
* 🛒 Buy & Sell NFTs
* 📦 Store assets on IPFS
* ⚡ Fast & low-cost transactions (Polygon)
* 📊 Blockchain-based ownership verification

## 🛠️ Installation & Setup

### 1️⃣ Clone the Repository

git clone https://github.com/Sharan4747/web3-music-nft-marketplace.git
cd web3-music-nft-marketplace

### 2️⃣ Install Dependencies

npm install

### 3️⃣ Run the Development Server

npm run dev

App will run on:
http://localhost:3000
